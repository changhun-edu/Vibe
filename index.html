바이브 코딩 연수 길잡이

말로 설명하면 AI가 코드를 써 주는 '바이브 코딩'으로 학교 업무용 웹사이트를 직접 만들어 배포합니다. 입문과정(2차시)부터 전문가과정(15차시)까지, 앞 과정 위에 다음 과정이 쌓입니다.

연수 개요

연수 전날까지 준비해 주세요

  • 필수구글 계정 — 비밀번호와 2단계 인증용 휴대폰을 함께 챙기세요. 학교 업무용 계정보다 개인 Gmail 계정을 권장합니다.
  • 필수노트북과 크롬 브라우저 최신 버전. 태블릿만으로는 파일 업로드가 불편합니다.
  • 필수유료 생성형 AI 1개 (기초과정 이상) — 무료 버전은 긴 코드를 중간에 끊거나 사용 횟수가 금방 바닥나 실습이 멈춥니다.

과정마다 필요한 준비물은 아래 과정별 계획표의 ※ 준비물에서 확인하세요.

과정별 연수 계획

실습 단계의 [따라 하기]는 2026년 10월 화면 기준이며, GitHub·Vercel·Firebase 등의 화면 구성과 버튼 이름은 바뀔 수 있습니다. 1차시는 60분 기준입니다. 연수 기관 기준이 50분이면 상세 진행 순서의 시간을 비율대로 줄여 운영하세요. 체크 표시는 이 기기의 브라우저에만 저장됩니다.

막혔을 때

Vercel 주소에 들어가면 404가 떠요404

파일 이름이 정확히 index.html(소문자)인지, 폴더 안에 넣지 않고 저장소 맨 위에 올렸는지 확인하세요.

GitHub에서 고쳤는데 사이트가 그대로예요

Commit 후 Vercel이 다시 배포하는 데 1~2분 걸립니다. 그래도 같으면 PC는 Ctrl+Shift+R, 휴대폰은 시크릿 창으로 열어 보세요.

AI가 코드를 쓰다가 중간에 멈춰요

"이어서 작성해 줘"라고 요청하세요. 자주 끊기면 "바뀐 부분만 보여 줘"로 요청 범위를 줄이고, 유료 요금제를 사용하세요.

Firebase에 저장이 안 돼요permission-denied

보안 규칙이 막고 있습니다. 테스트 모드는 만든 날부터 약 30일 뒤 자동으로 막히니 규칙의 날짜를 확인하세요. 9차시에서 제대로 된 규칙으로 바꿉니다.

구글 로그인 창이 안 떠요unauthorized-domain

Firebase 콘솔 → Authentication → 설정 → 승인된 도메인에 내프로젝트.vercel.app을 추가하세요. https://는 빼고 넣습니다.

API를 불렀는데 CORS 오류가 나요CORS

그 API가 브라우저에서 직접 부르는 것을 막는 경우입니다. 10차시의 Vercel 서버리스 함수(/api)로 대신 호출하면 해결됩니다.

학교에서 GitHub나 Vercel 접속이 안 돼요

학교망 차단일 수 있습니다. 휴대폰 핫스팟으로 연결해 보세요. 연수 담당자는 연수 전에 장소의 네트워크를 미리 점검해 주세요.

계정 만들기 바로가기

구글 계정 만들기모든 과정 필수 GitHub 가입코드를 올려 두는 곳 Vercel 가입"Continue with GitHub"로 가입 Firebase 콘솔구글 계정으로 바로 사용 NEIS 오픈API 인증키회원가입 후 인증키 신청 공공데이터포털미세먼지 등 활용 신청
